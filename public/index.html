1. Memahami Arsitektur Format Berkas grandMA2

        

          Konsol grandMA2 menyimpan dan mendistribusikan konfigurasi pencahayaan panggung melalui tiga jenis format utama:
        

        
A. Showfile Terkompresi (.show / .gz)

        

          Showfile grandMA2 standar merupakan aliran XML yang dikompresi menggunakan gzip dengan byte magic 0x1F 0x8B. 
          Elemen root <MA> mendefinisikan stream version, struktur setup, patch fixture, profil lampu, sekuens, cue, 
          dan tata letak executor. Rahul Light men-dekompresi gzip secara biner, menyesuaikan token skema, dan mengompresi ulang 
          menggunakan deflasi gzip standar konsol.
        


        
B. Ekspor Modular XML (.xml)

        

          Macro, Effect, Preset, dan Fixture Types yang diekspor dari meja konsol membawa header skema versi XML:
        

        
<MA xmlns="http://schemas.malighting.de/grandma2/xml/MA" major_vers="3" minor_vers="9" stream_vers="63" stream_sub_vers="6">

        

          Jika konsol yang menjalankan versi 3.9.60 membaca stream_vers="63", konsol akan membatalkan impor 
          dengan peringatan ketidakcocokan stream. Proses downgrade menyesuaikan token ini ke nomor versi konsol target.
        


        
C. Skrip Plugin Lua (.lua)

        

          grandMA2 memperkenalkan integrasi Lua pada versi 3.x. Namun, penambahan API baru seperti 
          gma.gui.progress atau gma.network.gethostdata tidak tersedia pada versi lama. 
          Rahul Light secara cerdas menyuntikkan shim fallback non-intrusif sehingga skrip tetap berjalan tanpa memicu crash fatal nil value.
        

      


      

        
2. Panduan Impor ke Konsol & Tata Letak Folder USB Resmi

        

          Agar berkas hasil konversi dapat dibaca oleh konsol fisik grandMA2 atau onPC, susun direktori flashdisk USB Anda sebagai berikut:
        

        
USB_ROOT/
└── gma2/
    ├── shows/          <-- Letakkan showfile (.show / .gz) di sini
    ├── importexport/   <-- Letakkan XML Macro, Effect, Preset, Fixture di sini
    ├── plugins/        <-- Letakkan Plugin (.lua) di sini
    ├── bitmaps/        <-- Letakkan ikon & tekstur (.png / .bmp) di sini
    └── library/        <-- Letakkan profil Fixture Type di sini

  1. Salin berkas hasil konversi dari Rahul Light ke folder USB yang sesuai.

  3. Tekan tombol fisik [Setup] pada meja konsol.
    4. 
          
  4. Pilih menu [Import / Export] di layar konsol.
    5. 
          
  5. Pilih drive USB Anda di tab bagian atas (misal Drive 2: USB).
    6. 
          
  6. Pilih berkas yang diinginkan dan tekan tombol [Import].
